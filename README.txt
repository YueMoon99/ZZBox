舟舟视频工具箱（ZZBox） v0.6.1  使用说明
==================================================

【怎么打开】
  双击 本文件夹里的 ZZBox.exe

  不需要 Python，不需要 FFmpeg，不需要联网。
  整个 ZZBox 文件夹可以拷到 U盘 或别的电脑直接用。

  （根目录的 启动.bat 也能开，它内部就是去调那个 exe，留着当备用入口）


【关闭窗口 = 缩到托盘，不退出】

  点右上角 X 只是把窗口收起来，程序继续在后台跑：

    · 正在压制时关窗口，压制不会中断，压完会弹通知告诉你结果
    · 屏幕右下角（Windows 11 在 ^ 里）会出现蓝色图标，那是它
    · 双击托盘图标 / 左键单击 = 把窗口叫回来
    · 右键托盘图标 = 菜单：
          第一行是当前状态和进度（灰色，不能点）
          显示主窗口
          开始压制        （窗口收起来后也能直接开压）
          取消当前任务    （有任务在跑时才亮）
          退出            ← 这是唯一真正退出程序的地方
    · 鼠标悬停在托盘图标上，能看到「舟舟视频工具箱 · 45% · 文件名」

  想让它一直待在任务栏上：Windows 11 的 ^ 里把它拖到任务栏外即可
  （系统默认把新图标收进折叠区，不是程序的问题）。

  如果正在压制时点退出，会先弹一次确认，避免误操作中断任务。


【怎么用】
  1. 把视频文件拖进窗口，或点右上角那个「+」
  2. 下面四个卡片设置参数：
       编码器 —— H.264 / HEVC / AV1（选哪个都能硬编）
       质量   —— CRF 滑块（越小画质越好，22 是常用值）
                 或者切到「码率」自己填 Mbps
       缩放   —— 25% / 50% / 100% / 200%
                 也可以在最右边输入框自己填：37 表示 37%，1280x720 表示指定尺寸
       音轨   —— 压缩 AAC（默认）/ 保留原样 / 删除
  3. 点右下角「开始压制」
  4. 进度条会显示百分比、加速倍率、剩余时间


【文件队列：一张表格，看得见体积】

  队列是一张六列表格，从左到右：

      文件名        双击这一列没反应，纯文本；太长会中间省略，鼠标悬停看全名
      原始格式      分辨率 · 帧率 · 时长，例：1920×1080 · 25fps · 03:29
      导出格式      同上，只是分辨率会跟着「缩放」变，帧率和时长不变
      原始大小      源文件体积
      预计导出大小  按当前编码器 / CRF / 缩放算出来的成片体积
      操作          状态圆点 + 状态文字 + 锁定 / 重提 / 删除

  改任何一个参数（编码器、CRF、码率、缩放），「导出格式」和「预计导出大小」
  两列会当场重算，不用等开始压。

  「预计导出大小」是怎么来的、准不准：
      按 CRF 与分辨率推算出视频码率，再加上音轨（AAC 160k）算总大小。
      这套系数是用你那份实拍素材实测标定的，回测六组设置误差都在 1% 内。
      但它是"同类素材"的统计规律，实拍里运动多、噪点多、场景切换密集的
      片子实际会偏大一些，通常 ±25% 浮动；用「码率」模式时最准，因为目标
      码率就是你直接指定的。把它当成"量级参考"，不要当成精确值。

  状态圆点：

      黄色  就绪     已入队，等待压制
      灰色  已锁定   不参与任何队列动作（用来临时跳过某几个）
      蓝色  压制中   正在编码，后面会跟着百分比
      绿色  已完成压制 / 已抽取音频 / 已删除音轨
              该行已经处理过，不会再被重复压
      红色  失败     编码出错或被手动停止

  行尾三个按钮：

      锁定   点一下变「已锁」，该文件不参与压制；再点一下解除
      重提   把状态重置为「就绪」并解除锁定，可以再压一次
              （已完成、失败的文件想重压，就点它）
      删除   从队列里移除，不影响硬盘上的源文件

  拖动排序：按住某一行上下拖，松手即可调整顺序，队列按新顺序压制。
  压制过程中不能拖动、也不能删除正在压制的那一行，避免队列错位。

  多选：
      · 单击选中一行；Shift 连选一段；Ctrl 加选 / 减选用在零散的几行
      · 在表格下方的空白处按住左键拖出一个框，框住的行就被选中
      · 选中之后，右上角的「重提所选」「删除所选」只作用于这几行

  右上角按钮：
      +          添加文件（也可以直接把视频拖进来）
      重提所选   把选中的行重置为「就绪」，可再压一次
      删除所选   把选中的行移出队列，不影响硬盘上的文件
      清空       清空整张队列

  右下角按钮：
      抽取音频   把所选（没选就全部）文件里的音轨导出成 .m4a
      删除音轨   只剥掉音轨，视频流原样拷贝、不重新压制
                 输出为「原名_无音轨.mp4」，源文件不动
      两个工具都是批量的：勾几行就处理几行，跑完状态分别是
      「已抽取音频」「已删除音轨」，产物默认落在「输出到」的目录里。

  列宽：把鼠标移到两个表头之间，按住左右拖（和资源管理器一样）。
        拖的时候只有这根线左边那一列变宽变窄，它右边所有列整体跟着平移，
        被拖的线始终贴着鼠标走。
        列宽的总和始终等于窗口宽，可拖动的余量由窗口宽度决定；操作列窄到
        刚好放得下指示灯和三个按钮就顶住，所以按钮永远不会被挤出可视区。
        窗口拉宽后余量会自动补给「文件名」列。
  表格高度：默认能看见 3~4 行，窗口拉高时跟着长高；
  文件多到装不下时右侧出现滚动条，鼠标滚轮可直接滚动。
  队列为空时表格中间会有一行提示文字，不会只剩一条光秃秃的表头。

【输出在哪】
  默认输出到源文件所在的文件夹，
  文件名是 原文件名_hevc_gpu.mp4 这样。
  想换地方就在底部「输出到」里选。


【关于体积：为什么同样的 CRF 比小丸大】

  v0.2 已修好，根因有三条。如果你之前压出 190MB、小丸只有 60MB，看这里：

  1) CRF 和 CQ 不是一个东西（主因）
     x264 的 CRF 是逐帧逐块自适应的感知质量；显卡只有 CQ，它只是给编码器
     一个质量提示。旧版按 crf-2 换算，方向反了——等于把小丸的 CRF25
     当成 CQ23 的高画质档来压，自然会大。

     实测（你那份实拍素材 30 秒切片，以 x264 CRF25 为画质基线）：
        设置                视频码率    画质SSIM   体积
        x264 CRF25（小丸）   3.49 Mbps  0.9885    1.00 倍
        旧版 等效 CQ23       7.60 Mbps  0.9940    2.18 倍
        新版 等效 CQ28       4.23 Mbps  0.9889    1.21 倍
     新版的 1.21 倍是硬件编码的固有代价（同画质下 NVENC 天生比 x264 多花
     15%~25% 码率），不是参数没生效。

  2) 音轨被原样搬过去了
     .mov 工程文件的音频常是 PCM 24bit，码率 2~3 Mbps。三分钟的片子光音频
     就 60MB。现在默认转 AAC 160k，并且源音频超过 256kbps 时即使选
     「保留原样」也会自动降级，界面会给出提示。

  3) 编码器没选对
     同画质下的体积：H.264 100%  /  HEVC 约 88%  /  AV1 约 75%


【想压得更小，怎么设】

  想 ≈ 小丸 CRF25 的体积      →  HEVC + CRF 26
  想再小 25% 左右              →  HEVC + CRF 29
  想再小且能接受兼容性风险     →  AV1 + CRF 26
  想极致小                     →  CPU x265 工具（如 ShanaEncoder），
                                  比本工具再小 25%~35%，代价是慢十几倍

  实测对照（同一段 30 秒素材，含 AAC 音轨，基准为小丸 CRF25）：
        H.264 CRF25  → 1.27 倍
        HEVC  CRF22  → 1.61 倍
        HEVC  CRF26  → 0.98 倍
        HEVC  CRF28  → 0.77 倍
        HEVC  CRF29  → 0.68 倍
        AV1   CRF25  → 0.93 倍

  CRF 滑块下方现在会直接写这组话（接近无损 / 高画质 / 均衡 / 小体积 /
  极小体积），不用再靠猜。

【顶部那个绿色标签】
  显示你的显卡和可用的编码器。
  点它可以看到详细的环境自检信息（显卡型号、驱动版本、FFmpeg 版本）。
  如果它是红色，说明环境有问题，点开截图发我。


【出问题了怎么办】
  1. 任务列表里显示「失败」——鼠标悬停在「失败」两个字上，会显示原因
  2. 启动时弹「启动失败」窗口——里面会写出日志文件路径，把那个文件发我
  3. 其他异常 —— 截图发我

  日志位置：本文件夹\logs\error.log


【想确认程序本身没坏，可以这样自检】
  按住 Shift 右键点本文件夹空白处 →「在此处打开 PowerShell 窗口」
  输入：.\ZZBox.exe --selftest
  它会自动生成一段测试视频、压一遍、报告结果。
  出现 RESULT = PASS 就说明显卡、编码器、FFmpeg 全部正常。


【这一版已知的限制】
  · 解码用 CPU、编码用 GPU。全 GPU 管线（硬解 + 显存内缩放）在 v0.6
  · HDR / 10bit 素材会被转成 8bit，颜色可能不对，v0.6 修
  · 队列是串行的，同时只压一个文件（GPU 并发反而更慢）
  · 没有暂停功能，只能取消整个队列
