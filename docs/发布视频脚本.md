## 三、制作指导书（HTML / CSS / JS）

### 3.1 规格

| 项 | 值 |
|---|---|
| 画布 | 1920 × 1080 |
| 帧率 | 60 fps |
| 时长 | 50 秒 |
| 输出 | H.264 / yuv420p / AAC 48kHz |

### 3.2 目录

```
video-promo/
├── index.html
├── style.css
├── timeline.js          # 场景表 + renderAt(ms) + 缓动
├── scenes/s1…s6.js
├── assets/ui/           # 截图与切片
├── assets/vo/           # 配音分句
└── render/              # 导出中间帧，不进版本库
```

### 3.3 时间轴

只暴露一个入口：`renderAt(tMs)`。

- 任意时刻都要能完整重算，不能依赖上一帧状态。
- 场景里不许用 `setTimeout` / `setInterval` / `rAF` 自推进。
- 渲染路径里不许读 `Date.now()` / `performance.now()`。同一时刻渲染两次，结果必须一致。
- 场景写成 `{ id, t0, t1, mount(root), update(p) }`，`mount` 只建一次 DOM，`update` 每帧改样式。

验证：`renderAt(20000)` 调两次，截图逐像素一致。

### 3.4 分层

| 层 | 技术 | 内容 |
|---|---|---|
| 背景 | CSS 纯色 | `#1b1b1e` |
| 窗口与面板 | DOM | 按真实尺寸重建框、行、按钮 |
| 图片 | img | 缩略图、画质对比图、截图切片 |
| 文字 | DOM | 标题、屏幕文字 |
| 字幕 | 独立 DOM 层 | 与口播对应 |

界面用 DOM 重画，不要整张截图贴上去——片子里数字在跳、行在动，截图动不了。只有缩略图、对比图用真图。

### 3.5 视觉

颜色取自程序本身：

```
背景 #1b1b1e   面板 #232327   描边 #2e2e34
主文字 #ececee  次要 #9c9ca3   说明 #7c7c84
强调 #185fa5   警示 #ef9f27
```

字体：中文 `"Microsoft YaHei UI", "PingFang SC", sans-serif`；数字 `"JetBrains Mono", ui-monospace, monospace`，加 `font-variant-numeric: tabular-nums`。

字号（1080p）：标题 96 / 镜内标题 56 / 屏幕文字 40 / 面板文字 26 / 字幕 38。

边距 96px，字幕基线上移 120px 避让播放器。关键内容留在中心 1080×1080，方便裁竖版。

### 3.6 动作

| 用途 | 做法 | 时长 |
|---|---|---|
| 元素出现 | 上移 20px + 透明度，easeOutExpo | 260 ms |
| 画质对比 | 光带擦除（clip-path 揭开） | 900 ms |
| 数字变化 | 数值插值，easeOutCubic | 500 ms |
| 换工作台 | 整层横移 100%，easeInOutCubic | 300 ms |

缓动写成纯函数，不要用 CSS animation——没法按时间点跳转。

**节奏**：痛点镜头压到最短（不超过 4 秒），解决方案镜头多给 2–3 秒。情绪切换用「低情绪 = 画面偏灰、略降速」「高情绪 = 画面回亮、动作提速 1.2 倍」来表现，不要靠字幕颜色喊。

### 3.7 数字滚动

1. 数字容器固定宽度，`tabular-nums`，否则滚动时左右抖。
2. 单位和数字分开，只滚数字。
3. 多行同时滚时每行错开 40ms 启动。

### 3.8 素材

- [ ] 四张界面截图（`docs/images/` 下），取色、量尺寸
- [ ] 5 个视频 + 若干图片的缩略图
- [ ] 文件图标（mp4 / mov / jpg / png）
- [ ] 一张糊/清画质对比图（同一帧，左右两版）
- [ ] 托盘图标
- [ ] 配音 6 段 wav，按句子切开
- [ ] 音效 3 个：转场、数字落定、完成提示

### 3.9 音画

先录配音，量出每句真实时长再回填场景起止点。场景起点对齐句首，别对齐句尾。配音 -14 LUFS，音乐 -18 LUFS 垫底，峰值 ≤ -1 dBTP。

静音看一遍要能看懂。

### 3.10 导出

- **预览**：实时播放 + `canvas.captureStream(60)` 录制，快，可能掉帧。
- **成片**：无头浏览器按 `t = i × 1000/60` 逐帧调 `renderAt` 截 PNG，再交 ffmpeg 合成。3000 帧，几分钟。

```
ffmpeg -framerate 60 -i render/%05d.png -i vo.wav \
  -c:v libx264 -crf 16 -pix_fmt yuv420p -c:a aac -b:a 192k out.mp4
```

### 3.11 交片前检查

- [ ] `renderAt(20000)` 两次结果一致
- [ ] 静音能看懂
- [ ] 数字滚动无布局位移
- [ ] 无文字截断或省略号
- [ ] 中文字体无跳字（预加载，`font-display: block`）
- [ ] 每帧渲染 16.7ms 内
- [ ] 时长 50 秒 ± 0.5 秒
- [ ] 1920×1080 / 60fps / yuv420p
